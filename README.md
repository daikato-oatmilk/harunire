# はるにれの丘（ベータテスト版）

東京の郊外の、小さなサンクチュアリを育てるゲームです。ブラウザで遊べます。アカウントやインストールは要りません。

- 遊ぶ：https://daikato-oatmilk.github.io/harunire/
- ご意見・感想：[はるにれの丘 ご意見・感想フォーム](https://docs.google.com/forms/d/e/1FAIpQLSdgJqfHECsHmITqt_SmSiokd6mo9tORm7hHo5p-myaBgJmTpQ/viewform)。SNSでつながっている方は、DMでのご意見や感想も歓迎です
- 進み具合は、遊んでいるブラウザの中に保存されます。ゲームの「設定」→「続きをファイルに」で、端末にファイルとして残せます

このリポジトリには、公開用のゲームのファイル（index.html）と、ゲームの中の「本当のお知らせ」（news.json）、リンクを送った時の絵（og.jpg）だけを置いています。
